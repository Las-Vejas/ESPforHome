# ESPforHome

A super small ESP32C6 devboard perfect for ESPHome.

It uses the ESP32-C6-MINI-1 and ESPHome for the software. 14 GPIO pins along with 2 GND, 1 3V3 and 1 5V pins are available to the user. The board is exactly 30mm x 30mm.
